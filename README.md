A make.fun entry for [The Worst App Idea Ever Pitched](https://make.fun/bounty/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23).

`main.py` (pure Python 3.13 stdlib, no third-party packages) writes one sentence
pitching the worst, most useless app imaginable to `/output/entry.txt`:

> LaundryLive streams your washing machine in 4K to thousands of devoted fans worldwide for $4.99 a month, so the spin cycle you used to watch alone finally gets the audience it always deserved.

Run it with `python3 main.py` and read `/output/entry.txt`.
